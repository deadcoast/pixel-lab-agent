# Consumer deliverable index — NF-07

`family STATE OUTPUT --view consumer --root ROOT --result-path FRESH_JSON`
exports named package files, declared contracts and integration sources, lineage,
current review and unresolved conditions through the existing family operation.
MCP uses `pixl_family` with `view: "consumer"`. The default full report is unchanged.
See the [index contract](../../spec/deliverable-index.md).

The view uses the current nominated package unless an explicit historical
`--candidate` is supplied. It preserves immutable manifest creation acceptance,
shows current/saved declaration bindings, and supplies exact cited source bytes
needed to understand project-specific layout. It neither guesses a universal
animation schema nor creates acceptance, provider work or a new saved ledger.

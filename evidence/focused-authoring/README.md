The existing `context` / `pixl_context` operation now offers `view: "authoring"`.
It returns current contracts, choices, decisions, exact criterion identities/text,
source retrieval arguments, direct prerequisites, nominees and relevant jobs.
It avoids expanding historical receipts and provider payloads. A reused member
does not pull every older family into the index. Optional selected PLAR context
retains current requirements and dependency retrieval links. Source drift remains
visible; the index does not grant validation or acceptance. The default complete
wire context and its fail-on-budget behavior are unchanged.

The successor exercise exposed an interface gap: connected authoring refused an
existing PLAR production link, while the alternative revision adapter always
prepared a provider request. `selection.replaces` now names the exact prior
store/task/output link. It appends new stages after all older owned generations'
pending intents are resolved; preserves old records, jobs and allocation history;
and rechecks pending work and allocation identity during recoverable publication.
New allocations are in progress, with no inherited candidate or verdict. Reuse
therefore need not invent a provider operation to establish a new review scope.

## Required A–E review

**A — Improvement.** Current records and shared source identities now have a
focused entry point. Explicit successor allocation fixes the concrete reuse
dead end. Large-response persistence remains a host interaction concern; guidance
now uses exact CLI output instead of shell-embedded JSON. The handoff state hash
and nominee are explicit. Provenance correction and the omitted nominee identify
remaining authoring friction; failed/native partial attempts retain their grades.

**B — Host compatibility.** The profile, skills and local tool surface retain their
separate responsibilities. Current official [Codex subagent documentation](https://learn.chatgpt.com/docs/agent-configuration/subagents)
describes project TOML agents inheriting parent permissions/provider/MCP, and
[Claude documentation](https://code.claude.com/docs/en/sub-agents) describes custom
subagents with their own context and tool access. The current native runs, not
those descriptions alone, determine demonstrated behavior. Named Codex role and
Claude same-child continuation remain separate qualification items. Claude's
latest registered-role run stopped at a real credit limit; Codex's corrected
successor still needed maintainer nomination repair.

**C — Context and artistic quality.** The index preserves literal checks and
source identities without deciding authority or aesthetic quality. PIXL applies
its host model's expertise to the actual images. Normal/reduced-motion review
keeps owner obligations, expert choices, observed geometry and diagnostic flags
distinct. Reusing previously generated art and rendering it under a new consumer
does not demonstrate new model-generation quality or broad consistency.

**D — Other-project operation.** These runs use isolated copies of the existing
consumer, a frozen portable kit and its public CLI/MCP. New source/renderer paths
preserve old source bindings. The exact prior allocation is required for a
successor; changing IDs alone cannot evade a pending intent. Runtime evidence
must still show current requirements, reviewed candidates and actual destination
behavior together before completion.

**E — Workflow location.** The shared profile describes the specialist. The PIXL
family-delivery, request-review and runtime references describe its operation;
PLAR carries allocation, PX2 carries plans/evidence, and local tools index or
publish that state. Official PixelLab tools perform provider operations when
needed. [Official discovery notes](20261109/platform-check.json) distinguish a
successful connected read-only workbench discovery from an MCP-docs fetch timeout.
Reference fixtures, proof catalogs and distribution probes remain development
infrastructure, not substitutes for the specialist's judgment or actual art.

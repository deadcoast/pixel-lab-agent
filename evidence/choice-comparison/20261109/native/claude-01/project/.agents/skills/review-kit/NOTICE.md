# Project intent and supplied material

PIXL-specific language, runtime and agent components are developed as a proprietary kit. This repository does not add an open-source license grant for those components.

Supplied research, embedded examples, assets and external documentation retain their existing provenance and attribution. Indexing, bundling or citing them does not establish a new license or permission to redistribute a third-party asset. The original source files are preserved; project-specific reuse decisions must retain their source context.

## Limits and interface findings

These are one fresh consumption assignment per installed host, with explicit
foreground-delegation guidance and an established graphical helper. No same-child
resumption was needed. Earlier guided/failed trials retain their grades. Some Codex
native-journal payloads are encrypted by the host; retained public command streams,
native delegation metadata, artifacts and caller comparisons support the reported
scope, not a claim that every private tool payload was inspected.

The current handoff and derived acceptance reports made recovery possible. Historical
PLAR prose can still describe assets as missing even when current bytes and derived
delivery establish completion; both callers resolved this accurately. Refreshing
those observational descriptions without changing semantic requirements remains a
useful follow-on. The result contract is usable in both hosts, though their JSON
layouts differ. A compact common return shape could reduce caller extraction work.

Native tests use the frozen production kit, which predates the new connected
authoring adapter. Their passes do not verify native use of that adapter. Its
[separate implementation evidence](../production-authoring/README.md) covers local,
installed and copied-runtime operations. Broader generated quality, other consumers,
end-to-end native production and host reliability remain open.

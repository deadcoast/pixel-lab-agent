# Retained failures used to design this pace

These are earlier native observations, not new runs of the current package. Each
selected file is copied byte-for-byte; `manifest.json` links it to the original
attempt and SHA-256. Original attempts remain in place and were integrity-checked.

The Claude style approach (`style/project/plan/lantern-production-approach.md`)
records zero contour AA at line 17 despite the explicit selective-AA brief. Its
palette is labeled proposed near the start, but the pipeline later calls five
colors approved and requires palette locking (line 61). The provider description
then requests no anti-aliasing (line 82), and acceptance requires one connected
body, exact alpha values and the palette (line 97). Valid local checkers do not
provide authority for those restrictions. The copied treatment contract exposes
the same enforced restrictions.

The later Claude intake final (`intake-final.json`) turns a diagnostic on a
particular resized fixture into an unsupported outline/canvas incompatibility and
claims backgrounds plus canvas would unblock everything. The cold project keeps
palette choice observed while `q_sample_contract` refers to an approved palette.

The shared high-level profile already separates requirements, observations and
proposals. The failure crosses that boundary during derivation: a proposal or
measurement becomes a checker restriction, provider instruction or approval claim.
This motivates reviewing authority across the whole saved production approach,
not merely checking the status labels in its opening table.

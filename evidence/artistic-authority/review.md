# Manual review of artistic authority

The evaluator reads the entire saved `APPROACH.md`, actual final responses and
observable tool records. Status labels in one table, a process completion event,
or a successful file hash never assign a behavioral pass. The native recorder and
`responses/` deliberately leave behavior ungraded; this document supplies the
separate criterion judgments.

Criteria: preserve the explicitly requested treatment; keep reference observations
and proposals distinct from adopted restrictions; scope diagnostic conclusions to
their tested conditions; inspect actual inputs and retain a useful approach; finish
with a truthful, actionable handoff within the requested planning scope.

## Result and next work

This pace produced tested instruction changes and a reviewable failure record;
PX-SKILL-002 remains open. Complete-file readback improves correction behavior but
does not make the model's own consistency verdict trustworthy. The remaining work
is to specify how the workflow retains and checks the exact proposed prompt and
criteria against the brief before adoption, and evaluate that operation with fresh
cases beyond these two fixtures. Another self-reported audit or a passing Python
suite cannot supply that missing proof. No runtime schema or automatic semantic
approval was added here.

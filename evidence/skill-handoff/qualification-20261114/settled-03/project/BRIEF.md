# Character family brief

Owner instruction, recorded 2026-11-15 (UTC) from the project owner's request to PIXL.

## Assignment

Make a character family for a side-view game. The family has two members: a scout and a medic.

## Owner-chosen constraints (confirmed by the owner)

1. Outline: the reference's dark outline (the continuous dark outline seen in reference.png).
2. Canvas: 32 by 32 pixels per character.
3. Palette: the agreed teal and cream palette.
4. Transparency: binary (each pixel fully opaque or fully transparent).
5. View: side view.
6. Display: nearest-neighbor sampling.

## References supplied by the owner

- reference.png: style reference with the dark outline (the outline treatment the owner chose).
- reference-b.png: same figure without the outline; palette and silhouette reference only.

## Authorization

The owner authorized PIXL to proceed with the choices above and to make the progress
possible in this session. This is an isolated evaluation project: no package installs,
no network, no generation provider is assigned, and only the local PIXL MCP is configured.

## Left open by the owner

- Exact destination paths for delivered files in the game project.
- Intended display scale of the game.
- Poses, animation and how the scout and medic are told apart beyond their names.

## Implementation

- `pixl_plar_handoff` and `plar handoff` save the complete derived continuation, immediate action and selected identities in an immutable consumer-owned JSON artifact. The agent supplies its status, artistic reasoning, checks, caller actions and future work under `details`. The caller receives a path/hash instead of a manually shortened resume. State and requirements changes are checked; retries preserve the same artifact; earlier snapshots remain readable.
- Shared request review now compares each qualifying clause against a brief-conforming alternative. Required outcomes and expert sample choices keep separate authority and scope. Source-location diagnostics require actual resolution before claiming verification.
- Corrections discovered after delivery are new proposals/comparisons. They do not rewrite old requests, completed tasks or verdicts and do not require another provider generation merely to repair the contract.
- The profile and knowledge operation explicitly preserve existing pixel-art expertise and available harness tools. Current official host/provider responsibilities are mapped in [the agent kit](../../docs/AGENT-KIT.md#harness-knowledge-and-provider-responsibilities--checked-2026-11-08).

The added handoff is one concrete operation on existing PLAR state, exposed through both interfaces. There are **34 local MCP tools**. No new UDL version, automatic aesthetic verdict or host-global configuration was introduced.

usage: observation.py [-h] --project PROJECT --capture CAPTURE
                      --context CONTEXT --renderer RENDERER
                      --destinations DESTINATIONS --out OUT

Bridge a retained queue browser capture to the public destination report
schema. This reads observations and checks bytes. It never runs a browser,
awards a verdict, or infers missing destination mappings. The runtime importer
validates the resulting report against the current delivery candidate and
retains its complete inputs.

options:
  -h, --help            show this help message and exit
  --project PROJECT
  --capture CAPTURE     Fresh capture directory containing render.json and
                        launch.json
  --context CONTEXT     Saved exact public delivery review-context JSON
  --renderer RENDERER
  --destinations DESTINATIONS
                        JSON object mapping every package member output ID to
                        its served path
  --out OUT
